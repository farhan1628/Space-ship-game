# 🚀 Space Shooter

A **two-player** space shooter game developed using C++ and raylib. Players control their own spaceships, navigate through a star-filled environment, and shoot projectiles at each other. The first player to hit their opponent wins!

## 🎮 Features

🚀 Two-player multiplayer gameplay.

💥 Shooting mechanics with separate projectiles for each player.

🌌 Randomized starting positions and star-filled space environment.

🎯 Bullet and spaceship collision detection.

✨ Explosion effects when a player gets hit.

🏆 Winner screen and replay functionality.

## 🕹️ Controls

### 🔵 Player 1

**Move**: Arrow Keys

**Rotate**: Left and Right Arrow Keys

**Shoot**: Right Shift

### 🔴 Player 2

**Move**: W, A, S, D

**Rotate**: A and D

**Shoot**: Left Shift

## 🎮 Game Navigation

**Space**: Proceed from the start screen.

**Enter**: Start the game.

**Q**: Play again after a winner is declared.

## 🛠️ Technologies Used

C++ – Core programming language.
raylib – Graphics, rendering, input handling, and collision detection.
STL – Vector-based projectile management.
Math Library – Movement, rotation, and projectile trajectories.
